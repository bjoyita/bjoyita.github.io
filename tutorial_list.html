How to run the code

I use Python in these tutorials. If you are starting out, Google Colab is a convenient way to run the examples. If you prefer to work on your own computer, use Jupyter Notebook.

Google Colab

Run Python in your browser without installing it on your computer. Open a new notebook, or upload a downloaded .ipynb file. Run the cells in order, starting with the imports and any installation instructions in the tutorial.

Open Google Colab ↗

Jupyter Notebook

Run the notebook on your own computer. Install Python, Jupyter Notebook, and the libraries listed in the tutorial. Keep the notebook and its input files in the expected folders, then run each cell in order.

See Jupyter installation instructions ↗

Try an example on this website

Some tutorials include interactive tools. Change a setting and inspect the result directly on the page. To study or change the Python code, use the accompanying notebook where one is provided.
