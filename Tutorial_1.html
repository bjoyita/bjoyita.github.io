Generation of Simulated Images

by Joyita Bhattacharya

I find it helpful to begin with an image whose pattern I already know. I can change the size or spacing of the shapes and see how these changes appear in the image and its Fourier transform.

In this post, I create a row of circles, a square grid of circles, and an image from a periodic function. These are simple test images, rather than simulations of how a material evolves.

Start with NumPy and Matplotlib

You can run the examples in a Jupyter notebook or Google Colab. NumPy creates and processes the arrays; Matplotlib displays the results. Run these imports first:

import numpy as np
import matplotlib.pyplot as plt

An image is an array of pixel values. In the circle examples, 0 marks the background and 1 marks a circle. The lengths below are measured in pixels; no physical length scale has been assigned.

1. Create a horizontal row of circles

I start with a 400 × 400 pixel array. Each circle has a radius of 10 pixels. Their centers are 20 pixels apart along the middle row, so neighboring circles touch. Circles centered on the image edges are partly outside the array.

Code Output 
Micro1 = np.zeros((400,400), np.uint8) 
center_x = 400/2
center_y = 400/2

x, y = np.ogrid[:400, :400]
for j in range(0, 401, 20):
  circles_w = (x-center_x)**2 + (y-j)**2 <= 10**2
  Micro1[circles_w]=1
  plt.imshow(Micro1, cmap ='gray')

Look at the Fourier transform

The Fourier transform describes the spatial frequencies in the image. A spatial frequency tells us how often a pattern repeats over a distance. Here I plot the magnitude of the transform, with zero frequency moved to the center by fftshift. The vertical streak reflects the narrow horizontal row in the original image. Its appearance also depends on the circle shape and the finite image size.

Code Output 
Micro1_f = np.fft.fft2(Micro1)
Micro1_f_shift = np.fft.fftshift(Micro1_f)
Micro1_shift=plt.imshow((abs(Micro1_f_shift)), cmap ='gray')
plt.colorbar(Micro1_shift)
plt.show()

I explain the transform further in my Fourier transform post.

2. Arrange circles on a square grid

Here I use another 400 × 400 pixel array. The code sets the circle radius to 5 pixels and places their centers 100 pixels apart in both directions. Notice that the radius is smaller than in the first example.

Code Output 
Box1 = np.zeros((400,400)) 

x, y = np.ogrid[:400, :400]

for i in range(0,420,100):
    for j in range(0,420,100):
        circles = (x-i)**2 + (y-j)**2 <= 5**2
        Box1[circles] = 1.0
plt.imshow(Box1, cmap ='gray')

The magnitude of its Fourier transform is shown below:

A repeated pattern produces regularly spaced features in Fourier space. If I increase the spacing between circles in the image, the corresponding frequency spacing becomes smaller. Try changing 100 to 50 in both loops and compare the results.

3. Make an image from a periodic function

I can also assign each pixel a value calculated from a function. Here I add a sine function of X to a cosine function of Y. The coordinates are dimensionless. The colors now represent the function value, rather than two separate regions.

The function used below is: f(X, Y) = sin(4πX) + cos(6πY). Here is the code and its two-dimensional image.

Code Output 
x= np.linspace(0, 6*np.pi, 50)
y= np.linspace(0, 6*np.pi, 50)
X,Y = np.meshgrid(x,y)
f = np.ones([50, 50])
f = np.sin(4*np.pi*X) + np.cos(6*np.pi*Y)
plt.imshow(f)

Next I plot the same values as a surface. X and Y give the horizontal coordinates; the height is f(X, Y). This is a height plot of the same two-dimensional function, not a three-dimensional microstructure.

Code Output 
fig, ax = plt.subplots(subplot_kw={"projection": "3d"})

# Plot the surface.
f_surf = ax.plot_surface(X, Y, f, cmap='jet')
                       
ax.view_init(60,120)
fig.colorbar(f_surf)

plt.show()

The surface makes the peaks and valleys easier to see. Try changing one frequency coefficient and plot both views again. The 50-point example is coarse and undersamples this function. Increase it to 500 points along each axis to resolve the oscillations more clearly. For higher frequencies, increase the sample count in each linspace call.
