Generation of Simulated Images

by Joyita Bhattacharya

Build patterns, understand their rules, and explore how changing those rules changes the image. I start with a single circle, then move through grids, stripes, checkerboards, criss-cross bands, random particles, and periodic fields. Additional examples vary checkerboard aspect ratio and orientation, curve the stripes, and change their white-to-black width ratio.

These controlled synthetic images help us learn how shape, spacing, orientation, arrangement, and phase fraction are represented by pixels. They can be useful test inputs for image analysis and microstructure statistics. No physical length scale or material evolution model is assigned here.

Start with NumPy and Matplotlib

Use a Jupyter notebook or Google Colab. If needed, install NumPy and Matplotlib first. Run the setup once, then run any example below.

import numpy as np
import matplotlib.pyplot as plt

N = 400
# First axis = row (y); second axis = column (x).
y, x = np.ogrid[:N, :N]

np.ogrid creates a column of row coordinates and a row of column coordinates. NumPy broadcasting combines them into a 400 × 400 mask. In each binary image, black is 0 (False) and white is 1 (True). Lengths are in pixels.

The examples use the usual image convention: the first array index is the row, and rows increase downward. All outputs below were generated by the displayed numerical rules.

1. Single circle

Select pixels whose distance from the center is no greater than the radius.

Target pattern

Python code

radius = 50
pattern = (x - N//2)**2 + (y - N//2)**2 <= radius**2

plt.figure(figsize=(5, 5))
plt.imshow(pattern, cmap='gray', vmin=0, vmax=1,
           origin='upper', interpolation='nearest')
plt.xlabel('Column (x)')
plt.ylabel('Row (y)')
plt.tight_layout()
plt.show()
print('White area fraction:', pattern.mean())

Generated output

How it works. The inequality creates a Boolean mask: True inside the circle and False outside.

Try it. Change radius from 50 to 80. How does the white area change? Predict the result before running the code.

2. Horizontal row of circles

Place equal circles along the middle row, with a gap between neighboring circles.

Target pattern

Python code

radius, spacing = 12, 40
pattern = np.zeros((N, N), dtype=bool)
for cx in range(spacing//2, N, spacing):
    circle = (x - cx)**2 + (y - N//2)**2 <= radius**2
    pattern |= circle

plt.figure(figsize=(5, 5))
plt.imshow(pattern, cmap='gray', vmin=0, vmax=1,
           origin='upper', interpolation='nearest')
plt.xlabel('Column (x)')
plt.ylabel('Row (y)')
plt.tight_layout()
plt.show()
print('White area fraction:', pattern.mean())

Generated output

How it works. The loop moves the center horizontally. |= adds each circle by taking the logical union of masks.

Try it. Set radius to 20: neighboring circles now touch because the diameter equals the spacing. Predict the result before running the code.

3. Square grid of circles

Repeat circles at equal intervals along both image axes.

Target pattern

Python code

radius, spacing = 12, 50
pattern = np.zeros((N, N), dtype=bool)
for cy in range(spacing//2, N, spacing):
    for cx in range(spacing//2, N, spacing):
        pattern |= (x - cx)**2 + (y - cy)**2 <= radius**2

plt.figure(figsize=(5, 5))
plt.imshow(pattern, cmap='gray', vmin=0, vmax=1,
           origin='upper', interpolation='nearest')
plt.xlabel('Column (x)')
plt.ylabel('Row (y)')
plt.tight_layout()
plt.show()
print('White area fraction:', pattern.mean())

Generated output

How it works. Nested loops visit every combination of row and column centers.

Try it. Change spacing to 40 while keeping the radius fixed. Compare particle count and white area. Predict the result before running the code.

4. Horizontal and vertical stripes

Alternate white and black bands. Show both orientations explicitly.

Target pattern

Python code

width = 20
horizontal = np.broadcast_to((y//width) % 2 == 0, (N, N))
vertical = np.broadcast_to((x//width) % 2 == 0, (N, N))
pattern = horizontal

plt.figure(figsize=(5, 5))
plt.imshow(pattern, cmap='gray', vmin=0, vmax=1,
           origin='upper', interpolation='nearest')
plt.xlabel('Column (x)')
plt.ylabel('Row (y)')
plt.tight_layout()
plt.show()
print('White area fraction:', pattern.mean())

Generated output

How it works. // gives the band index; % 2 alternates between even and odd bands. broadcast_to repeats the row or column rule across the image.

5. Checkerboard

Divide the image into square tiles. A tile is white when its row index plus column index is even.

Target pattern

Python code

tile = 40
pattern = ((x//tile + y//tile) % 2) == 0

plt.figure(figsize=(5, 5))
plt.imshow(pattern, cmap='gray', vmin=0, vmax=1,
           origin='upper', interpolation='nearest')
plt.xlabel('Column (x)')
plt.ylabel('Row (y)')
plt.tight_layout()
plt.show()
print('White area fraction:', pattern.mean())

Generated output

How it works. Each neighboring tile changes the sum by one, so its color switches. Diagonal neighbors retain the same color.

Try it. Use different tile widths along x and y to produce rectangular checks. Predict the result before running the code.

6. Diagonal stripes

Use the sum of row and column coordinates to draw repeating diagonal bands.

Target pattern

Python code

width = 20
pattern = ((x + y)//width) % 2 == 0

plt.figure(figsize=(5, 5))
plt.imshow(pattern, cmap='gray', vmin=0, vmax=1,
           origin='upper', interpolation='nearest')
plt.xlabel('Column (x)')
plt.ylabel('Row (y)')
plt.tight_layout()
plt.show()
print('White area fraction:', pattern.mean())

Generated output

How it works. Constant x+y defines a diagonal line. width is measured in the coordinate sum; the perpendicular band width is width/√2 pixels.

Try it. Replace x+y with x-y. What happens to the direction? Predict the result before running the code.

7. Criss-cross diagonal bands

Combine two families of diagonal bands to make a diamond network.

Target pattern

Python code

period, band = 80, 10
diagonal_1 = (x + y) % period < band
diagonal_2 = (x - y) % period < band
pattern = diagonal_1 | diagonal_2

plt.figure(figsize=(5, 5))
plt.imshow(pattern, cmap='gray', vmin=0, vmax=1,
           origin='upper', interpolation='nearest')
plt.xlabel('Column (x)')
plt.ylabel('Row (y)')
plt.tight_layout()
plt.show()
print('White area fraction:', pattern.mean())

Generated output

How it works. | means logical OR: a pixel is white if it belongs to either family. At crossings the bands join.

Try it. Replace | with &: only the intersections remain. Compare the two patterns. Predict the result before running the code.

8. Staggered rows of circles

Offset every alternate row by half the horizontal spacing.

Target pattern

Python code

radius, spacing = 12, 50
row_spacing = 43
pattern = np.zeros((N, N), dtype=bool)
for row, cy in enumerate(range(25, N, row_spacing)):
    offset = (row % 2) * (spacing//2)
    for cx in range(25 + offset, N, spacing):
        pattern |= (x - cx)**2 + (y - cy)**2 <= radius**2

plt.figure(figsize=(5, 5))
plt.imshow(pattern, cmap='gray', vmin=0, vmax=1,
           origin='upper', interpolation='nearest')
plt.xlabel('Column (x)')
plt.ylabel('Row (y)')
plt.tight_layout()
plt.show()
print('White area fraction:', pattern.mean())

Generated output

How it works. enumerate supplies a row counter as well as the center coordinate. Alternate offsets change the arrangement without changing circle size. The row spacing approximates a triangular arrangement.

Try it. Set offset to zero to recover aligned rows. Predict the result before running the code.

9. Randomly placed circles

Use a reproducible random seed to choose particle centers.

Target pattern

Python code

radius, count = 15, 45
rng = np.random.default_rng(7)
centers = rng.integers(radius, N-radius, size=(count, 2))
pattern = np.zeros((N, N), dtype=bool)
for cy, cx in centers:
    pattern |= (x - cx)**2 + (y - cy)**2 <= radius**2

plt.figure(figsize=(5, 5))
plt.imshow(pattern, cmap='gray', vmin=0, vmax=1,
           origin='upper', interpolation='nearest')
plt.xlabel('Column (x)')
plt.ylabel('Row (y)')
plt.tight_layout()
plt.show()
print('White area fraction:', pattern.mean())

Generated output

How it works. Each pair contains a row and column center. Circles may overlap; their union is white, so the white area is not generally count × π × radius².

Try it. Change the seed to 8, then increase count. Distinguish a new realization from a change in particle density. Predict the result before running the code.

10. Smooth periodic field and a two-phase pattern

Build a smooth field, then turn it into two regions by applying a threshold.

Target pattern

Python code

u = np.linspace(0, 1, N, endpoint=False)
X, Y = np.meshgrid(u, u)
field = np.sin(2*np.pi*4*X) + np.cos(2*np.pi*6*Y)
threshold = 0.3
pattern = field > threshold

plt.figure(figsize=(5, 5))
plt.imshow(pattern, cmap='gray', vmin=0, vmax=1,
           origin='upper', interpolation='nearest')
plt.xlabel('Column (x)')
plt.ylabel('Row (y)')
plt.tight_layout()
plt.show()
print('White area fraction:', pattern.mean())

Generated output

How it works. There are four cycles along x and six along y. endpoint=False avoids duplicating the periodic endpoint. The threshold assigns each pixel to one of two regions.

View the continuous field before thresholding

plt.imshow(field, cmap='viridis', origin='upper')
plt.colorbar(label='Field value')
plt.show()

View the same field as a surface

fig, ax = plt.subplots(subplot_kw={'projection': '3d'})
surface = ax.plot_surface(X, Y, field, cmap='viridis')
ax.set(xlabel='x', ylabel='y', zlabel='Field value')
fig.colorbar(surface, ax=ax, shrink=0.7)
plt.show()

Try it. Raise the threshold to 0.8. Predict whether the white fraction increases or decreases. Predict the result before running the code.

12. Rotated checkerboard

Rotate the coordinate system before applying the checkerboard rule. This produces alternating diamond-shaped tiles.

Target pattern

Python code

angle = np.deg2rad(45)
xc, yc = x - N/2, y - N/2
u_rot = xc*np.cos(angle) + yc*np.sin(angle)
v_rot = -xc*np.sin(angle) + yc*np.cos(angle)
tile = 40
pattern = ((np.floor(u_rot/tile) + np.floor(v_rot/tile)) % 2) == 0

plt.figure(figsize=(5, 5))
plt.imshow(pattern, cmap='gray', vmin=0, vmax=1,
           origin='upper', interpolation='nearest')
plt.xlabel('Column (x)')
plt.ylabel('Row (y)')
plt.tight_layout()
plt.show()
print('White area fraction:', pattern.mean())

Generated output

How it works. The two rotated coordinates remain perpendicular. floor gives the tile index on both positive and negative coordinates. This is a filled checkerboard; the criss-cross example instead contains narrow crossing bands.

Try it. Change the angle to 30 degrees. Rotation changes orientation while keeping the nominal tile size. Predict the result before running the code.

13. Wavy stripes

Shift horizontal bands by a sinusoidal amount that varies across the columns.

Target pattern

Python code

period, white_width = 40, 20
amplitude, wavelength = 12, 160
shift = amplitude*np.sin(2*np.pi*x/wavelength)
pattern = (y - shift) % period < white_width

plt.figure(figsize=(5, 5))
plt.imshow(pattern, cmap='gray', vmin=0, vmax=1,
           origin='upper', interpolation='nearest')
plt.xlabel('Column (x)')
plt.ylabel('Row (y)')
plt.tight_layout()
plt.show()
print('White area fraction:', pattern.mean())

Generated output

How it works. Every column shifts the same stripe rule up or down. amplitude controls the displacement; wavelength controls the distance between successive crests. The stated band width is measured vertically, not normal to the curved boundary.

Try it. Set amplitude to zero to recover straight stripes. Then halve wavelength to make the bands bend more frequently. Predict the result before running the code.

Compare the patterns in Fourier space

Now that the patterns are recognizable, compare their spatial frequencies. The following block constructs horizontal stripes, a checkerboard, and criss-cross bands from the same rules above. It puts their Fourier outputs below their real-space images.

stripe_mask = np.broadcast_to((y//20) % 2 == 0, (N, N))
checker_mask = ((x//40 + y//40) % 2) == 0
cross_mask = ((x+y) % 80 < 10) | ((x-y) % 80 < 10)
patterns = [stripe_mask, checker_mask, cross_mask]
titles = ['Horizontal stripes', 'Checkerboard', 'Criss-cross']

from matplotlib.colors import PowerNorm

half_window = 60  # Show the central 121 frequency bins.
display_floor = -50  # dB relative to each pattern's strongest peak.
gamma = 0.45  # Below 1 brightens intermediate colors.
spot_size = 28  # Marker area in points squared, not frequency width.
for title, mask in zip(titles, patterns):
    fig, axes = plt.subplots(2, 1, figsize=(7, 10), constrained_layout=True)
    axes[0].imshow(mask, cmap='gray', vmin=0, vmax=1)
    axes[0].set_title(title)
    # Subtract the mean to remove the dominant zero-frequency term.
    centered = mask.astype(float) - mask.mean()
    spectrum = np.fft.fftshift(np.fft.fft2(centered))
    magnitude = np.abs(spectrum)
    peak = magnitude.max()
    relative = magnitude / peak if peak > 0 else np.zeros_like(magnitude)
    db = 20*np.log10(np.maximum(relative, 1e-12))
    center = N//2
    crop = db[center-half_window:center+half_window+1,
              center-half_window:center+half_window+1]
    # Enlarge visible frequency bins for teaching; do not blur FFT data.
    row_bin, col_bin = np.nonzero(crop >= display_floor)
    norm = PowerNorm(gamma=gamma, vmin=display_floor, vmax=0)
    image = axes[1].scatter(
        col_bin-half_window, row_bin-half_window,
        c=crop[row_bin, col_bin], cmap='inferno', norm=norm,
        s=spot_size, edgecolors='none')
    axes[1].set_facecolor('black')
    axes[1].set_xlim(-half_window-0.5, half_window+0.5)
    axes[1].set_ylim(-half_window-0.5, half_window+0.5)
    axes[1].set_aspect('equal')
    axes[1].set_title('Fourier bins: enlarged markers, brighter colors')
    axes[1].set_xlabel('Column frequency (cycles/image)')
    axes[1].set_ylabel('Row frequency (cycles/image)')
    axes[0].axis('off')
    fig.colorbar(image, ax=axes[1], shrink=0.8,
                 label='Relative magnitude (dB; nonlinear color mapping)')
    plt.show()

Why Fourier spots can look faint

A periodic pattern concentrates its transform into isolated frequency bins. In a 400 × 400 FFT, a peak can occupy just one array pixel. Shrinking three panels onto a phone makes that pixel smaller still. Even a bright peak then looks faint because it covers so little screen area.

Amplitude contrast is a separate issue. On a linear scale, a strong zero-frequency (DC) component or fundamental peak can dominate the color range and leave weaker harmonics almost black. np.log1p(np.abs(spectrum)) compresses this range, but it does not enlarge isolated pixels or guarantee that weak values receive bright colors.

How this code improves visibility

First, subtract the mean to suppress DC. Next, normalize the magnitude and use 20*np.log10(...): a magnitude of 0.1 relative to the maximum is −20 dB, and 0.01 is −40 dB. Keep the logarithm finite using a small positive floor. Then select the central frequency window and display each pattern separately, at a readable size.

PowerNorm(gamma=0.45) brightens intermediate colors. It maps a normalized color coordinate t to t0.45; for example, t=0.25 becomes approximately 0.54. This affects display colors only. gamma=1 restores linear color mapping; a smaller gamma brightens intermediate colors further.

scatter(..., s=28) gives each visible frequency bin a readable marker area in points squared. Increase spot_size to 45 for larger dots. These enlarged markers indicate bin positions, not measured spectral widths. For an actual pixel map or peak-width analysis, use imshow(crop, norm=norm, cmap='inferno', interpolation='nearest', origin='lower') instead.

Multiplying the entire spectrum by a constant generally does not help when Matplotlib rescales the color limits automatically: the normalized color values stay the same. Adjust the color mapping, display limits, plot size, or marker size instead. For comparisons of absolute amplitudes, retain a shared normalization rather than normalizing each pattern separately.

Horizontal stripes vary vertically, so their Fourier peaks lie along the vertical frequency direction. The checkerboard contains periodicity in both directions. The criss-cross network produces diagonal frequency families normal to the corresponding bands. Sharp binary edges also produce higher harmonics.

Increasing a repeating real-space period brings its Fourier peaks closer to the center. Mean subtraction suppresses the central DC component; the decibel scale makes weaker features visible. The code uses 20 log₁₀ of normalized Fourier magnitude, equivalent to 10 log₁₀ of normalized power. Each panel is normalized to its own strongest peak. Compare relative peak strengths, not absolute amplitudes across panels. The display crops to ±60 cycles per image and clips colors below −50 dB; it leaves the Fourier data unchanged. Set half_window to 100 for a wider view, or display_floor to −70 to reveal weaker peaks. A less negative floor, such as −30, emphasizes the strongest peaks. Higher-frequency harmonics outside the crop still exist.

What these examples do—and what they leave open

Each pattern is a controlled test case, not a claim that all materials look this way. The main limitation is idealization: most examples repeat exactly, and random circles can overlap. Rasterized boundaries also depend on pixel resolution. Before using a generated image for quantitative work, check area fraction, feature dimensions, connectivity, overlaps, and sensitivity to resolution. Opposite image edges do not automatically match; periodic boundary conditions require an explicit check, especially for rotated or curved patterns.

Connect these patterns to microstructures

Circles can represent idealized particle sections; stripes can represent lamellar arrangements; criss-cross bands can represent connected networks. These are geometric analogues. Real microstructures additionally have distributions of sizes, shapes, crystallographic orientations, and interfaces. A 2D white area fraction should not automatically be called a 3D volume fraction without appropriate stereological assumptions.
