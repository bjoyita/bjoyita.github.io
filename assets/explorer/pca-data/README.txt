Synthetic materials dataset for the PCA article

300 specimens, five quantities, seed 110. These values are generated for teaching and are not experimental measurements or predictions for a particular alloy. The first six records are shown in the article. Units appear in each column heading. The XLSX and CSV contain the same rounded numerical values.

Generator: generate-data.mjs
Run with Node.js: node generate-data.mjs
Article: https://bjoyita.github.io/posts/pca-materials.html
